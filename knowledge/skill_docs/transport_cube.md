# transport_cube

- 参数: `color` (str, 可选) — 目标方块颜色，如 "red" / "green" / "blue"；缺省为最近的方块
- 前置条件: 方块在机械臂可达范围内；无其他物体遮挡
- 行为: 移动到方块上方 → 下降 → 闭合夹爪抓取 → 抬升 → 移动到悬浮目标球 → 送入球内触发判定 → 释放
- 失败模式:
  - 抓取失败：方块未被夹住（is_grasped=false），多见于下降高度不足或方块贴边
  - 放置失败：方块未送入目标球区域（success=false）
- 注意: 目标球悬浮在桌面上方约 0.21m，必须把方块手持送进球内，而非放到桌面
